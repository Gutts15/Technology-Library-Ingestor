## Original contract and user clarification

The original implementation baseline was the existing private Google Drive
and a separate public GitHub processing repository, with bounded jobs and no
impact on other projects. Normal operation must remain free of mandatory
additional recurring cost, paid inference fallback, personal-PC dependence,
Work-session dependence and recurring human review/publication approval.
Private input, extracted content, credentials and processing state remain private.
The current completion criterion is representative scheduled daily-flow acceptance.
The earlier 500-input example is optional load testing, not a required user dataset.

On 2026-10-08 the user challenged a request for an Oracle account because it
introduced a dependency absent from the initial plan. The correction was
accepted and the user requested documentation updates and continued work.
No provider/account requirement or migration was approved. Oracle was only
an engineering candidate, mistakenly communicated as a prerequisite.

The Charter allows initial credential/setup administration; that exception
does not by itself approve a replacement cloud provider. Do not ask for
Oracle signup as the next required step. Evaluate the existing baseline first.
This clarification does not assert that every future account is forbidden,
or that an unqualified existing resource satisfies the product contract.
